# Snellheid Industries™

Moving fast. Circling back. Source for [www.snellheid.com](https://www.snellheid.com), served by GitHub Pages.

Snellheid Industries is a fictional conglomerate and a long-running joke about corporate life. Nothing here is real, except the friendship.

## Structure

A static site in plain HTML, CSS and JS. There is no build step, framework or dependency.

| Page | What's on it |
| --- | --- |
| `index.html` | Hero, origin story timeline, Dirk quote rotator, Thought Leadership Engine™ (buzzword generator) |
| `products.html` | Nine divisions (Fast Glasses™, Snellcoin, MaaS, SnellGPT…) and a comparison table |
| `leadership.html` | The C-suite (generated SVG avatars), a circular org chart, the board |
| `investors.html` | $SNEL chart, KPIs, earnings call transcript, Snellcoin waitlist, risk factors |
| `careers.html` | Values, benefits, jobs with a runaway submit button, Performance Review Generator with certificate download |
| `breakroom.html` | Meeting Simulator with buzzword bingo, and Flappy Snail |
| `portal.html` | Secret employee portal (codeword or Konami code) |
| `404.html` | "I'll be back." |

```
assets/
  css/snellheid.css   design system (colours sampled from the logo)
  css/fonts.css       self-hosted fonts (Montserrat, Space Mono, Squada One; SIL OFL)
  js/core.js          shared header/footer, EN/NL switch, $SNEL ticker, toasts, confetti, easter eggs
  js/*.js             one file per toy/page
  img/                logo cut-outs, favicons, social share image
```

## Bilingual (EN/NL)

Both languages live side by side in the markup:

```html
<span data-l="en">Moving fast.</span><span data-l="nl">Snel bewegen.</span>
```

CSS hides whichever language isn't active. Text generated by JavaScript uses `Snel.t({ en: '…', nl: '…' })`. The chosen language is remembered, and the default follows the browser language.

## Editing

- **Header / footer / nav:** `renderHeader()` and `renderFooter()` in `assets/js/core.js`.
- **Dirk's quotes:** `assets/js/dirk.js`.
- **Portal codeword** (currently `illbeback`): `CODE_HASH` in `assets/js/portal.js`. To compute a new hash, run this in the browser console:
  `(s=>{let h=2166136261;for(const c of s){h^=c.charCodeAt(0);h=Math.imul(h,16777619)}return h>>>0})('newword')`.
  This is a static site, so the portal is an easter egg, not security.
- **Colours:** the `:root` tokens at the top of `snellheid.css`.

## Run locally

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

Use a local server rather than `file://`, so the 404 page and the certificate download work.
